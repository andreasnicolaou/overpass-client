OverpassClient

A wrapper for the Overpass API to query OpenStreetMap data — with retries, exponential backoff, and LRU caching. This page runs the real library in your browser, loaded straight from a CDN with no bundler.

GitHub npm Overpass API

Loaded on this page

<script src="https://unpkg.com/@andreasnicolaou/overpass-client"></script>
<script>
  const client = new OverpassClient.OverpassClient();
</script>

The UMD build is self-contained — Axios, RxJS and lru-cache are bundled in, so this is the only script tag the library needs.
